# Community Event Scheduler

## Project Description

Community Event Scheduler is an ASP.NET Core MVC web application designed to help members of a community organize events without creating scheduling conflicts.

Users can view upcoming community events for free and search by date, city, location, or event category. If a user wants to reserve a date for an event, they can create an account, log in, select an available date, and submit a booking request.

The system will help prevent multiple major events from being scheduled on the same date within the same area. Events in different cities or regions may still be scheduled on the same day when they do not create a conflict for the community.

Examples of events include:

- Weddings
- Funerals
- Birthday parties
- Community meetings
- Conferences
- Celebrations
- Religious events
- Other community events

## Main Features

- User Registration and Login
- View community events
- Search events by city and date
- Filter events by category
- Event booking
- Location-based scheduling conflict detection
- Event categories
- Payment for event reservations
- Email booking confirmation
- Admin event management
- Booking management

- CSS

- GitHub

## Project Goal

The goal of this project is to create a centralized community calendar where people can check existing events before selecting a date for their own event.

This will help community members coordinate events more effectively and reduce scheduling conflicts within the same geographic area.
